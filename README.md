# Landing Page

Projeto de landing page (The Odin Project) em HTML e CSS.

## Como publicar no GitHub Pages
1. Envie todos os arquivos para a raiz de um repositório (`index.html` deve ficar na raiz).
2. No GitHub: Settings > Pages > Source: "Deploy from a branch" > Branch: `main` / pasta `/ (root)` > Save.
3. Aguarde alguns minutos e acesse `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Imagens
Coloque as imagens na pasta `images/` (ex.: baixadas do Pexels) e use `src="images/arquivo.jpg"` no HTML.
